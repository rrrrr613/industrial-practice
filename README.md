# Интернет-магазин (Индивидуальное задание №5)

## Описание
Программный модуль интернет-магазина на Node.js с использованием ООП.

## Технологии
- Node.js (ES Modules)
- JavaScript (ООП)
- Встроенные модули: crypto, fs

## Функционал
- ✅ Управление каталогом товаров
- ✅ Поиск и фильтрация товаров
- ✅ Корзина покупателя (добавление/удаление/изменение)
- ✅ Оформление заказа с расчетом скидки и доставки
- ✅ Управление статусами заказа
- ✅ Обработка исключений и валидация
- ✅ Модульные тесты

## Установка и запуск

```bash
# 1. Клонирование
git clone https://github.com/your-username/internet-shop-node.git
cd internet-shop-node

# 2. Установка зависимостей (только для тестов)
npm install

# 3. Запуск демонстрации
npm start

# 4. Запуск тестов
npm test
